# Visvesh Manickam — Portfolio

A modern, cinematic personal portfolio website built with pure **HTML, CSS, and JavaScript** — no frameworks, no build tools needed.

## ✨ Features

- **Matrix Rain Canvas** — animated falling character background
- **Custom Cursor** — dot + lagging ring with hover morphing
- **Typewriter Effect** — cycles through developer roles
- **Scroll Progress Bar** — neon green indicator at top
- **Page Loader** — cinematic intro with animated fill
- **Mouse Parallax** — hero content shifts with cursor
- **3D Card Tilt** — project cards tilt toward mouse
- **Glitch Text** — name flickers with RGB split on hover
- **Counter Animation** — stats count up on scroll into view
- **Skill Bars** — fill animation triggered by scroll
- **Project Filter** — filter cards by tech stack
- **Infinite Marquee** — scrolling tech stack band
- **AOS** — scroll-reveal animations on all sections
- **Fully Responsive** — mobile-first hamburger menu

## 🎨 Theme: Neon Matrix

| Token | Value |
|---|---|
| Background | `#000000` |
| Accent | `#39ff14` (neon lime) |
| Font (display) | Space Grotesk |
| Font (mono) | JetBrains Mono |

## 🚀 Usage

Just open `index.html` in any browser — no server or build step required.

## 📝 Customization

Update the placeholder content in `index.html`:
- Your name, role, and bio
- Project cards with real GitHub/live links
- Experience timeline entries
- Contact email and social links
